# بازبینی امنیتی (SEC-001..009)

> **وضعیت SEC-009: «پیاده‌شده و نیازمند شاهد».** ارزیابی مستقل بیرونی (آزمون نفوذ یا بازبینی کد توسط متخصص امنیت مستقل از تیم ساخت) انجام نشده است. آنچه در این سند آمده **خودبازبینی تیم ساخت** (عامل پیاده‌ساز) با آزمون‌های خودکار است و جایگزین ارزیابی مستقل نیست. پیش از انتشار عمومی باید یک متخصص یا شرکت مستقل نام‌برده شود و گزارش او ضمیمه شود؛ تا آن زمان این مورد پذیرفته‌شده نیست.

## کنترل‌ها و شاهد
| محور | کنترل | شاهد (آزمون/ابزار) |
|---|---|---|
| احراز هویت و نشست | OTP با نرخ‌محدودی، نشست httpOnly SameSite، قفل پس از تلاش‌های ناموفق، MFA اجباری در تولید، لغو فوری نشست با تعلیق/حذف | identity.test.ts، app.test.ts، admin `esp07.test.ts` (تعلیق → نشست‌ها بسته) |
| CSRF | تغییر با کوکی بدون `X-Requested-With: fetch` رد می‌شود؛ Bearer مستثنی | api `esp07.test.ts` «CSRF header» |
| XSS | متن کاربر فقط متن (Vue escaping)، پاک‌سازی ورودی خبر/تیکت/نظر، CSP در تولید، بدون HTML خام | news/community tests؛ `v-html` فقط یک‌جا (QR محلی ساخته‌شده از توکن خودمان، `MyQrView`) و هیچ ورودی کاربر نیست |
| SSRF | فقط https، رد IP خصوصی/loopback/link-local/multicast (IPv4/IPv6 و mapped)، بدون credential در URL، بدون redirect؛ بررسی هنگام ثبت و هر ارسال | core `esp07.test.ts` (SSRF guard) |
| IDOR | همه دسترسی‌ها با مجوز + دامنه سمت سرور؛ رویداد/فایل/تراکنش رویداد دیگر FORBIDDEN/404 و تلاش حسابرسی می‌شود | `acceptance/ac.test.ts` AC-17؛ acl.test.ts |
| آپلود | تشخیص نوع با magic bytes (نه نام)، محدودیت اندازه، اسکن ClamAV (خرابی = رد)، قرنطینه، لینک خصوصی امضاشده کوتاه‌مدت، فایل حذف‌شده خوانده نمی‌شود | files.test.ts، clamav.test.ts (پروتکل)، AC-18 |
| راز | رازها فقط رمزشده (AES-GCM)، یک‌بار نمایش، پس از نمایش هرگز بازگردانده نمی‌شوند؛ لاگ با redact؛ چرخش با `APP_SECRET_PREVIOUS` | core `esp07.test.ts` (rotation)، identity.test.ts (log redaction) |
| محدودیت سوءاستفاده | rate-limit سراسری، سهمیه تیکت (۱۰/ساعت)، سهمیه API شریک، سهمیه ارائه‌دهنده، admission control (۵۰۳ به جای OOM) | بار میانی ۵۰۰ rps بدون خطا |
| حسابرسی | زنجیره هش، حذف/ویرایش ممکن نیست، حسابرسی تلاش‌های رد‌شده، بازبینی زنجیره پس از بازیابی | `ops/backup.test.ts` (audit chain)، `/ops/audit/verify` |
| سرآیندها | helmet (HSTS/CSP در تولید)، nosniff، `X-Frame-Options: DENY`، `Permissions-Policy`، `Referrer-Policy: no-referrer` | api `esp07.test.ts` |
| زنجیره تأمین | lockfile پین‌شده، نصب frozen، فهرست مجوزها | `docs/release/license-inventory.md`؛ `pnpm audit` اجرا نشد (نیازمند دسترسی شبکه؛ بخش «محدودیت‌ها») |

## محدودیت‌های صادقانه
- ارزیابی مستقل (SEC-009) انجام نشده؛ آزمون نفوذ پویا (DAST) و fuzzing اجرا نشده است.
- `pnpm audit` و پایگاه آسیب‌پذیری‌ها در این محیط اجرا نشد؛ باید در CI/محیط دارای دسترسی اجرا و نتیجه ثبت شود.
- ClamAV واقعی نصب و آزمون نشده؛ فقط پروتکل با stub.
- محدودیت نرخ و سهمیه در حافظه هر فرایند است (چند replica ⇒ سهمیه هر replica)؛ برای مقیاس افقی باید مخزن مشترک شود.
- دفاع در برابر DNS-rebinding کامل نیست (بررسی دوباره هنگام ارسال، pin کردن آدرس انجام نشده).
