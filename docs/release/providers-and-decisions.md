# ارائه‌دهندگان و تصمیم‌ها

منبع واحد تصمیم‌ها `DECISIONS.md` است؛ این فایل وضعیت ارائه‌دهندگان را در تحویل ESP-07 خلاصه می‌کند. **هیچ ارائه‌دهنده‌ای پیش‌انتخاب نشده و هیچ حساب سرویس ساخته نشده است**؛ انتخاب پس از ارزیابی توسط مالک انجام می‌شود (ثبت و ارزیابی در `/admin/integrations`).

## قاعده انتخاب
ایرانی یا خودمیزبان؛ یا استثنای مستند ناشر برای یک عنوان بازی. «انتخاب» فقط با: آزمون موفق، مرجع قرارداد/شرایط، طرح خروج، و ثبت نام متغیرهای کلید (نه مقدار) ممکن است. فهرست مجاز دامنه‌های شبکه از ارائه‌دهندگان انتخاب‌شده ساخته می‌شود؛ ارسال به نشانی دیگر مجاز نیست.

## وضعیت ارائه‌دهندگان
| دسته | وضعیت در کد | وضعیت تولید |
|---|---|---|
| پرداخت | interface + شبیه‌ساز؛ production بدون ارائه‌دهنده → `PROVIDER_NOT_CONFIGURED` | مسدود تا قرارداد/درگاه |
| پیامک/OTP | interface + شبیه‌ساز | مسدود تا ارائه‌دهنده ایرانی |
| ایمیل | interface + شبیه‌ساز | مسدود تا انتخاب |
| ذخیره فایل | `local` روی volume پشتیبان‌گیری‌شده | پیاده‌شده؛ نیازمند شاهد دیسک تولید |
| اسکن فایل | **ClamAV خودمیزبان** (`SCANNER_ADAPTER=clamav`, `CLAMAV_HOST/PORT`)؛ نبود/قطع clamd هرگز «پاک» نمی‌دهد و بارگذاری را رد می‌کند | پروتکل با stub آزموده شد؛ نیازمند شاهد با clamd واقعی |
| پخش/ویدئو | interface؛ بدون ارائه‌دهنده صفحه صریحاً «پیکربندی نشده» می‌گوید | مسدود تا سرویس ایرانی/خودمیزبان |
| نقشه | interface؛ آدرس متنی همیشه نمایش داده می‌شود | اختیاری |
| ناشر بازی | `none`؛ مسیر دستی کامل | فقط با مجوز و امکان واقعی |
| متریک/لاگ/خطا | متریک Prometheus در `/ops/metrics` (بدون PII)؛ جمع‌آوری خودمیزبان | نیازمند نصب collector توسط عملیات |

## ایمنی در برابر خرابی
هر فراخوان ارائه‌دهنده از `resilient()` می‌گذرد: retry محدود فقط برای عملیات idempotent، circuit breaker (۵ شکست، ۳۰ ثانیه)، سهمیه در دقیقه؛ خطای کسب‌وکار مدار را باز نمی‌کند. شکست‌هایی که می‌مانند به صف outbox/اعلان/وب‌هوک می‌روند و پس از تلاش‌ها dead-letter می‌شوند و قابل replay‌اند.

## تصمیم‌های ESP-07
D-054…D-064 در `DECISIONS.md` (ثبت شده در همین مرحله): دفتر حذف بیرون از پشتیبان، پیش‌فرض‌های نگهداری، اسناد هویتی/مالی مسدود تا سیاست مصوب، API شریک با HMAC، وب‌هوک منتظر تأخیر پخش، admission control و micro-cache پس از یافته بار، کلید گردان رازها، backup رمزشده منطقی، جداسازی مجوزها، فایل fail-closed هنگام خرابی اسکنر.
