# فهرست آمادگی بازی‌ها

هیچ بازی واقعی برای تولید فعال نشده است: فقط بازی ترکیبی آزمون (`game_seed_synthetic`، برچسب TEST ONLY) وجود دارد. افزودن هر عنوان واقعی فقط پس از تکمیل **همه** موارد زیر برای همان عنوان مجاز است؛ هر مورد نامشخص «مسدود عملیاتی» است و در سامانه جعل نمی‌شود.

| # | شرط برای هر عنوان | چه کسی تأیید می‌کند | وضعیت پیش‌فرض |
|---|---|---|---|
| ۱ | شناسه رسمی بازی، نسخه و پلتفرم(ها) و حالت‌ها در کاتالوگ (`/games`) | مدیر کاتالوگ | نامشخص |
| ۲ | **بسته قانون بررسی‌شده** (بندها با ارجاع و متن اصلی/فارسی، امتیازدهی، تساوی‌شکن، قطع اتصال، حداکثر توقف، ابزارهای مجاز) و انتشار نسخه‌دار | حقوقی/داور ارشد | نیاز به بررسی انسانی |
| ۳ | مجوز یا شرایط ناشر برای برگزاری مسابقه، پخش و استفاده از نام/لوگو | مالک/حقوقی | نامشخص |
| ۴ | وضعیت API/داده ناشر (در دسترس / محدود / ندارد) — پیش‌فرض `none` ⇒ ثبت دستی لابی/نتیجه با مدرک | مالک | `none` |
| ۵ | شیوه نتیجه (دستی با مدرک/اسکرین‌شات/دمو) و سیاست نگهداری دمو (۹۰ روز پیشنهادی) | داور ارشد | دستی |
| ۶ | سرور بازی: ایرانی/خودمیزبان یا لابی بازیکن؛ ظرفیت و منطقه | عملیات | ثبت نشده |

یادداشت: داده‌های بازی (نسخه/نقشه/حالت) هیچ‌گاه از اینترنت خارجی در زمان اجرا خوانده نمی‌شوند؛ ورود دستی/بسته‌ای است.
