# سیستم طراحی — Violet Arena

## توکن‌ها
فایل `apps/web/src/styles/tokens.css`: یک رنگ تأکید (بنفش)، مقیاس خنثی، رنگ‌های معنایی (ok/warn/danger/info)، فاصله‌ها `--sp-1..7`، شعاع‌ها، مقیاس تایپوگرافی `--fs-xs..2xl` و ارتفاع خط ۱٫۸۵ برای متن فارسی.
برای کاربران جدید تم تیره پیش‌فرض است؛ ترجیح ذخیره‌شده کاربران قبلی حفظ می‌شود. `[data-theme="dark"]` تم تیره را اعمال می‌کند. در حالت «سیستم» ویژگی `data-theme` حذف می‌شود و `prefers-color-scheme` تصمیم می‌گیرد.

## تایپوگرافی
فونت Vazirmatn فقط از فایل‌های محلی بسته‌ی `vazirmatn` (بدون CDN و Google Fonts). ارقام با تنظیم کاربر نمایش داده می‌شوند و `font-variant-numeric: tabular-nums` برای اعداد (`.num`).

## RTL و BiDi
- `<html lang dir>` با زبان تنظیم می‌شود: `fa` به `rtl`، `en` به `ltr`.
- از ویژگی‌های منطقی CSS (`inline-start`، `margin-inline`…) استفاده شده تا چیدمان خودکار جهت عوض کند؛ نوار کناری سمت راست در فارسی.
- متن مختلط: `<bdi>`، `.bidi` و `.ltr` (`unicode-bidi: isolate`)؛ سلول‌های جدول `dir="auto"`؛ شناسه‌ها، نام‌های انگلیسی، نسخه‌ها و آدرس‌ها در `<bdi class="ltr">` یا `<code>`.
- ورودی‌های عددی `dir="ltr"` با تراز مطابق جهت صفحه.

## ارقام، تاریخ، پول
- ورودی: ارقام فارسی، عربی-هندی و لاتین با `normalizeDigits` یکسان به ASCII تبدیل می‌شوند (`DigitInput`)؛ مدل همیشه ASCII است.
- نمایش: ارقام فارسی/لاتین طبق تنظیمات؛ در زبان انگلیسی همیشه لاتین.
- تاریخ: `JalaliDate` با `formatInstant` و منطقه‌ی `Asia/Tehran`؛ ذخیره‌سازی UTC.
- پول: مبلغ به ریال صحیح؛ `MoneyLabel` با `formatToman` برچسب «تومان» را نشان می‌دهد.

## تم و دسترس‌پذیری (WCAG 2.2 AA)
چک‌لیست:
- [x] لینک «پرش به محتوا» و فوکوس روی `<main>` پس از هر ناوبری
- [x] حلقه‌ی فوکوس 3px در `:focus-visible`
- [x] برچسب برای تمام فیلدها، `aria-describedby` برای راهنما/خطا، `role="alert"` برای خطا
- [x] جدول با `<caption>` و `<th scope>`؛ در موبایل به‌صورت کارت‌های انباشته
- [x] وضعیت‌ها فقط با رنگ منتقل نمی‌شوند (متن برچسب)
- [x] حرکت کاهش‌یافته با `prefers-reduced-motion`
- [x] آیکن‌ها SVG درون‌خطی با `aria-hidden`
- [x] هدف لمسی حداقل ۴۴px برای دکمه‌ها
- [ ] بررسی دستی کنتراست و صفحه‌خوان (انجام نشده؛ نیازمند مرورگر)

## ریسپانسیو
زیر ۹۰۰px نوار کناری به کشو تبدیل می‌شود (دکمه‌ی منو، Esc و پس‌زمینه برای بستن). زیر ۶۴۰px جدول‌ها انباشته می‌شوند.

## فهرست مؤلفه‌ها
`AppShell`، `TopBar` (چیپ اتصال، تم/زبان/ارقام)، `SideNav`، `PageHeader`، `DataState` (loading/empty/error/forbidden/offline؛ خطای NETWORK به offline و FORBIDDEN/UNAUTHENTICATED به forbidden نگاشت می‌شود)، `DataTable`، `FormField`، `DigitInput`، `JalaliDate`، `MoneyLabel`، `StatusBadge`، `ErrorNote`، `Icon`.

## i18n
`src/i18n.ts` با `t(key)` واکنشی؛ پیام‌ها در `locales/fa.ts` و `locales/en.ts` (کلیدهای انگلیسی از نوع فارسی اجباری می‌شوند). همه‌ی `ErrorCodes` و حالت‌ها (`statesFa` از contracts) پوشش دارند.

## بازطراحی آرنا

این نسخه طبق انتخاب کاربر، هویت آرنای حرفه‌ای، رنگ بنفش و سایت عمومی با پنل مجزا دارد. پایه‌ی قواعد و توکن‌ها از MCP رسمی [وایب فارسی](https://vibefarsi.ir/mcp) دریافت شده‌اند (`get_design_rules`, `scaffold_page`, `get_theme`, `get_component`). تم Graphite با تأکید بنفش تطبیق داده شده؛ کامپوننت‌های React به Vue منتقل شده‌اند، بدون افزودن React یا تغییر قراردادهای API.

- صفحات عمومی: منوی افقی، محتوای تمام‌عرض در قاب محدود، فوتر؛ منوی کشویی زیر ۹۰۰px.
- صفحات نیازمند احراز هویت/مجوز و تنظیمات حساب: سایدبار گروه‌بندی‌شده با همان مجوزهای قبلی.
- خانه: هیرو، جست‌وجو، مسیرهای کشف، فید رویداد/خبر و شمارنده‌های **همین فهرست دریافتی**؛ آمار کل پلتفرم یا وضعیت زنده ساختگی نمایش داده نمی‌شود.
- رویدادها: نمای کارتی یا فهرستی، جست‌وجو و فیلتر وضعیت فقط روی صفحات دریافت‌شده؛ صفحه‌بندی API فعال می‌ماند.
- خبرها: خبر اول برجسته، نمایش تصویر واقعی در صورت وجود؛ حالت کم‌مصرف تصاویر را بارگیری نمی‌کند.
- بازی‌ها، ورود و حساب: چیدمان تازه؛ رتبه‌بندی: فیلترهای شبکه‌ای و جدول قابل اسکرول.
- تمام صفحات از توکن‌ها، کنترل‌ها، جدول‌ها و حالت‌های مشترک جدید استفاده می‌کنند؛ Overlayهای پخش همچنان بدون پوسته‌اند.
- آیکن‌ها از `@lucide/vue` با واردکردن صریح آیکن‌های موردنیاز؛ وابستگی UI دیگری افزوده نشده است.
- کشوی موبایل: انتقال فوکوس، گردش Tab داخل کشو، بستن با Escape و بازگرداندن فوکوس؛ محتوای اصلی هنگام بازبودن کشو inert است.

## اعتبارسنجی بازطراحی

تست‌های `redesign.test.ts` جداسازی پوسته عمومی/پنل، بازوبسته‌شدن منوی موبایل، برگشت فوکوس، فیلتر رویدادها، تعویض نما و حفظ صفحه‌بندی را بررسی می‌کنند. تست‌های CSS موجود نیز از آینه‌شدن تصادفی کل صفحه در RTL جلوگیری می‌کنند.

مرورگر ابری این جلسه به سرور محلی وصل نشد (`ERR_CONNECTION_REFUSED`). بنابراین تصاویر قبلی در `docs/release/evidence/screens` مربوط به نسخه پیشین‌اند و شاهد بصری این بازطراحی نیستند. بررسی بصری دسکتاپ/موبایل، کنتراست و صفحه‌خوان پیش از انتشار نهایی باقی مانده است.
