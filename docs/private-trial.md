# Private UI exercises

When development login is enabled and the server is not staging/production, an authorized rules publisher can publish their own TEST ONLY package without marking publisher rights as reviewed. Translation review, clause validity, conflicts, human-review acknowledgements and role checks still apply. The audit records the development-trial path and the rules snapshot keeps its TEST ONLY label.

Published TEST ONLY rules can be used with a proposed/under-review game only by a private, free, unrated event with no prizes. The game must exist, list the discipline platform and mode, and have a matching module. Suspended/archived games are rejected. This never creates a readiness record, changes game state, promises integration support, or marks publisher rights reviewed.

Disabling development login removes these allowances. Staging/production always rejects TEST ONLY rules. Normal rules retain independent-author publication and publisher-rights review. Synthetic rules without a rights review cannot escape the private exercise gate even if the game is otherwise ready.

All hosted trial data is entered through the website forms; this change includes no seeding command or data import.
